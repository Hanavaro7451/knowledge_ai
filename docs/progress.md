# AI Knowledge Platform — прогресс

**Дата фиксации:** 2026-11-20

**Этап:** минимальное FastAPI-приложение и PostgreSQL в Docker Compose; основной функционал MVP ещё не реализован.

## Согласовано
- Концепция AI Knowledge Platform, backend-first, локальные Ollama и embeddings, нулевой бюджет.
- Ограничения MVP: JWT auth + refresh, доступ к собственным документам, текстовый PDF до 100 МБ, MinIO, PostgreSQL/pgvector, Celery/Redis, RAG по одному выбранному документу, ответ с проверенными источниками.
- UI/PySide6, история диалогов и расширенные возможности вынесены за MVP.
- Разработчик пишет backend руками; Codex — ревьюер и наставник.

## Пока НЕ подтверждено
- Сохранение данных после пересоздания контейнера PostgreSQL с прежним volume.
- Включение расширения vector в рабочей базе; сейчас расширение доступно, но не активировано.
- Redis, MinIO, таблицы приложения, миграции, auth/document/query endpoints, workers и Ollama integration.
- Выбор конкретных LLM и embedding-модели.

## Проверено 2026-11-20
- Создано минимальное FastAPI-приложение и `GET /api/v1/health`.
- Проведено ревью первого endpoint и HTTP-теста; тест проверяет HTTP 200 и JSON `{"status": "ok"}`.
- Запуск pytest: `1 passed, 1 warning`; отдельно выводится предупреждение pytest-asyncio. Предупреждения зависимостей/конфигурации пока не устранены.
- `docker compose config --quiet` проходит. Сервис PostgreSQL использует образ `pgvector/pgvector:0.8.7-pg17`, named volume и публикацию порта только на `127.0.0.1:5432`.
- После запуска Docker Desktop контейнер БД запущен; в логах есть `database system is ready to accept connections`, `pg_isready` сообщает `accepting connections`.
- SQL-запросы внутри контейнера подтвердили подключение к базе `knowledge` и доступность pgvector 0.8.7; `installed_version` пустой.
- Следующий шаг: проверить сохранение тестовой записи после пересоздания контейнера без удаления volume.
